# Getting Started with Docker

Docker lets you package an application with its dependencies into a container.

## Key commands

- `docker build -t myapp .`
- `docker run -p 8080:8080 myapp`
- `docker ps`

Containers share the host kernel, which makes them much lighter than virtual machines.
